# Git Add & Commit

After making changes in your project, you need to **stage** and **save** them in Git.  
This is done using `git add` and `git commit`.

---

## 1. Git Add

Adds your **changed or new files to the Staging Area**, preparing them for commit.

### Syntax

```bash
git add <filename.txt>
git add .

## 2. Git Commit

Saves the staged changes to your local Git repository and keeps a permanent record.

git commit -m "Write your message here"

Key Insight

## Think of it this way:

- git add → put items into a box (staging area)

- git commit → seal the box and label it (save permanently in Git)
