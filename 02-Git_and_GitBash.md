# What is Git?

Git is a **Version Control System** used to track changes in code or files over time.

**Created by:** Linus Torvalds (2005)

## Key Features of Git

- Free and open-source
- Distributed Version Control System
- Fast, secure, and reliable
- Tracks changes with full history
- Enables team collaboration

---

# What is Git Bash?

**Git Bash** is a command-line tool (terminal) that allows you to run Git commands.

It comes bundled when you install **Git on Windows**.
