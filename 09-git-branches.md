# Git Branches

Branches allow you to **work on different lines of development** in a project simultaneously and merge them back when ready.

---

## 1. Main Branch (Production)

The **primary line of development**.  

- Commit 1 through Commit 5 show the **chronological history** of the main project.

---

## 2. Branching Out

- **Branch 3:** Created from the state of Commit 1.  
  Follows its own path with **four independent commits**.

- **Branch 2:** Created from the state of Commit 2.  
  Follows its own path with **three independent commits**.

---

## 3. Branch Merge

- **Branch 2 Merge:** The changes from Branch 2's "Commit 3" are merged back into the **main branch at Commit 5**.  
- **Branch 3 Merge:** The changes from Branch 3's "Commit 4" are also merged back into the **main branch at Commit 5**.

---

## Summary of Concepts

- **Branching:** Allows you to work on **new features or bug fixes** without affecting the main code.  
- **Merging:** The process of taking the changes from one branch and **integrating them into another**.
