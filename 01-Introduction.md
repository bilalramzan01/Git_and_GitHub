# Git and GitHub

## Version Control System (VCS)

A **Version Control System (VCS)** is a tool or software that helps you track changes made to files over time.

It allows you to:

- Save different versions of a project
- Go back to an earlier version
- Work with a team on the same project
- See who made changes, what was changed, and when

# Examples of Version Control Systems (VCS)

## Examples of VCS

| Name | Type | Description |
|-----|-----|-------------|
| Git | Distributed VCS | Most popular. Used by developers to track code changes. |
| Subversion (SVN) | Centralized VCS | Older system where all files are stored in a central server. |
| Mercurial | Distributed VCS | Similar to Git, known for performance and simplicity. |
| CVS | Centralized VCS | One of the first version control systems, now outdated. |
| Perforce | Centralized VCS | Used in large enterprises and gaming companies. |

---

## Types of Version Control Systems

**Centralized VCS**  
All data is stored in one central server.  
Example: SVN

**Distributed VCS**  
Every user has a full copy of the repository.  
Examples: Git, Mercurial
