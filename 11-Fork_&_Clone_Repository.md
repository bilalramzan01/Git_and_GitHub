# Fork (GitHub)

A **fork** is a personal copy of someone else's repository created under your own GitHub account.  
It allows you to experiment with changes without affecting the original project.

---

## Key Points About Fork

- **Creates a separate copy** of the original repository in your GitHub account.  
- You can **edit, modify, or add new features** in your forked repository freely.  
- Commonly used to **contribute to open-source projects**.  
- After making changes, you can **send a Pull Request (PR)** to the original repository owner to request merging your changes.
