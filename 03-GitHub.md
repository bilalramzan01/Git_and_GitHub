# GitHub

## What is GitHub?

GitHub is a website where you can store your **Git projects online**.

---

## Background

- **Launched by:** Tom Preston-Werner, Chris Wanstrath, and PJ Hyett  
- **Year:** 2008  
- **Owned by:** Microsoft (since 2018)

---

## Key Features

- Online hosting of **Git repositories (repos)**
- Team collaboration and code sharing
- Issue tracking for bugs and tasks
- Support for **public and private repositories**
