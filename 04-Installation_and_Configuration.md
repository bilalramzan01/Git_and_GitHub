# Things To Do Before Using Git & GitHub

## 1. Create a GitHub Account

Follow these steps to create a GitHub account:

1. Go to https://github.com
2. Click **Sign Up**
3. Enter your:
   - Email address
   - Password
   - Username
4. Verify your email address.
5. Complete the setup process.

Now your **GitHub account is ready**.

---

## 2. Download & Install Git / Git Bash

Steps to install Git:

1. Go to the official website: https://git-scm.com
2. Click **Download for Windows**.
3. Run the downloaded installer.
4. Follow the installation steps and keep the default settings.
5. Finish the installation.

### Verify Installation

Open **Git Bash** and run:

```bash
git --version
